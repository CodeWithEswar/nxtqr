Augments native scrolling with custom cross-browser Precision Rail scrollbars without sacrificing native accessibility.

## Overview

The `ScrollArea` component wraps `@radix-ui/react-scroll-area` with NXTQR's tactile solid-neumorphic tracks and thumbs. It supports single-axis and dual-axis navigation, four thickness variants, and dynamic user accent integration.

## Canvas Isolation Note

When using `variant="canvas"`, the underlying viewport automatically receives `overscroll-behavior: contain`. This guarantees that scrolling a properties inspector or node palette to the top/bottom boundary will not zoom or pan the background graph canvas.
