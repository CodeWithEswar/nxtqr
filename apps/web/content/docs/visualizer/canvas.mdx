The `GraphCanvas` component serves as the central visual workspace for all NXTQR engineering visualizers. Built upon `@xyflow/react` and layered with ELK.js automated graph layout, it provides responsive panning, zooming, selection box dragging, snap-to-grid alignment, and undo/redo history management.

## Architecture & Principles

1. **Pure Black Canvas**: Baseline canvas is pure black (`#000000`). Grids use restrained neutral dots or lines without noisy glow effects.
2. **Dynamic User Accent**: Selection rings and marquee borders inherit the user's calibrated accent color (`ring-accent`, `border-accent`).
3. **Automated Hierarchical Layout**: Integrates ELK.js (`layoutGraphWithElk`) to automatically position nodes along clean left-to-right or top-to-bottom layers without overlapping edges.
4. **Decoupled State**: Graph document state lives in `@nxtqr/state` via `useGraphEditorStore`, ensuring zero re-render cascades across unselected nodes.

## Public Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `className` | `string` | `undefined` | Custom CSS container classes |
| `showToolbar` | `boolean` | `true` | Display floating viewport navigation and layout toolbar |
| `showMinimap` | `boolean` | `true` | Display bottom-right spatial minimap |
| `height` | `string \| number` | `"480px"` | Canvas container viewport height |

## Keyboard Shortcuts

| Shortcut | Action | Scope |
| :--- | :--- | :--- |
| **`Delete` / `Backspace`** | Delete selected node or edge | Canvas focused |
| **`Ctrl+Z` / `Cmd+Z`** | Undo last graph operation | Global canvas |
| **`Ctrl+Y` / `Cmd+Shift+Z`** | Redo graph operation | Global canvas |
| **`Escape`** | Deselect active node / edge | Global canvas |
| **`+` / `-`** | Zoom in / Zoom out | Canvas focused |
