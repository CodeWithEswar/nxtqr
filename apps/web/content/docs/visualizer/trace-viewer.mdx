The `ExecutionTraceViewer` component is NXTQR's primary runtime debugging interface. It presents a chronological, sub-millisecond timeline of simulation events, allowing engineers to filter by status or node name, inspect structured telemetry payloads, and synchronize element selection with the graph canvas.

## Core Capabilities

1. **Sub-Millisecond Chronological Stream**: Displays execution events with relative offsets (e.g. `+14.2ms`), step indices, and duration badges.
2. **Search & Status Filtering**: Real-time keyword filtering across node labels, target IDs, and event types with status filters (`All`, `Success`, `Failure`).
3. **Bidirectional Selection Sync**: Clicking a trace event automatically selects and centers the corresponding node on the graph canvas.
4. **Structured JSON Telemetry**: Displays parsed input/output metadata, memory footprint, and duration metrics.
