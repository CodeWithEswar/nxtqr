The NXTQR color system is divided into two strict architectural layers: **Structural Grayscale Hierarchy** and **Dynamic User Accents**. The interface uses a pure black base (`#000000`), crisp monochrome surfaces, and saturated accent highlights calibrated to maintain WCAG 2.1 AA/AAA accessibility.

## Color Architecture & Principles

Per NXTQR Constitution §3, color application follows strict rules:

1. **Pure Monochrome Baseline**: Dark theme surfaces are neutral grayscale with zero blue, slate, or purple tints. Canvas background is `#000000`.
2. **Never Hardcode Accents**: UI controls must reference semantic CSS tokens (`bg-accent`, `text-accent`, `text-accent-foreground`, `border-accent`, `ring-accent`).
3. **Contrast Compliance**: Foreground text on accent surfaces is automatically derived via `@nxtqr/design-system` contrast math. High-luminance accents (e.g. Pure Yellow `#FFD600`, Pure Orange `#FF6600`) receive `#000000` text, while low-luminance accents receive `#FFFFFF`.
4. **Prohibited Patterns**: Decorative gradient backgrounds, multi-color card borders, and fake colored glow effects are strictly forbidden.

## Grayscale Hierarchy

| Token Name | Hex Value | CSS Variable | Application |
| :--- | :--- | :--- | :--- |
| **Canvas / Base** | `#000000` | `--background` | Full-page backdrop and infinite visualizer canvas |
| **Surface** | `#0A0A0A` | `--surface` | Panels, toolbars, compact cards, sidebars |
| **Elevated Surface** | `#141414` | `--elevated-surface` | Modals, dialogs, floating inspectors, popovers |
| **Secondary Surface** | `#1A1A1A` | `--secondary-surface` | Recessed wells, active toggle states, code blocks |
| **Border** | `#262626` | `--border` | Structural container borders, panel dividers |
| **Subtle Border** | `#1C1C1C` | `--subtle-border` | Table grid lines, subtle divider strokes |
| **Foreground** | `#FFFFFF` | `--foreground` | Primary text, titles, high-contrast symbols |
| **Muted Text** | `#A3A3A3` | `--muted-foreground` | Secondary descriptions, captions, metrics |
| **Disabled Text** | `#737373` | `--disabled-foreground` | Inactive controls and unselected tabs |

## Implementation Reference

To apply color tokens in your component markup:

```tsx
import { colors } from "@nxtqr/design-system";

// Primary action button using dynamic accent
<button className="bg-accent text-accent-foreground font-semibold px-4 py-2 rounded-md transition-opacity hover:opacity-90">
  Execute Pipeline
</button>

// Engineering inspector panel using Level 1 surface and subtle border
<div className="bg-surface border border-border rounded-md p-4 space-y-2">
  <span className="text-xs font-mono text-muted-foreground">NODE_BUFFER_STATE</span>
  <h4 className="text-sm font-semibold text-foreground">Synchronized Buffer</h4>
</div>
```

## Accessibility & Contrast

- **WCAG 2.1 AA Normal Text**: Minimum contrast of 4.5:1 is required for body copy and data labels.
- **WCAG 2.1 Large Text & UI**: Minimum contrast of 3.0:1 is required for headings and interactive borders.
- **Focus Indicators**: Dynamic accent rings must maintain a 1px offset against dark surfaces to ensure immediate visibility for keyboard navigators.
