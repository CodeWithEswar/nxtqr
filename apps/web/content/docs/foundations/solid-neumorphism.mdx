NXTQR implements **Solid Neumorphism**—an engineering-focused design aesthetic inspired by physical audio hardware, oscilloscopes, and precision laboratory instruments. Unlike soft or blurry neo-skeuomorphism, NXTQR surfaces are solid, opaque, and geometrically disciplined.

## Architectural Principles

1. **Pure Opaque Surfaces**: Surfaces never use transparent alpha channels with backdrop blur (`backdrop-blur`). Backgrounds are `#0A0A0A` (Raised) or `#1A1A1A` (Recessed).
2. **Directional Inset Highlights**: A crisp 1px highlight (`inset 0 1px 0 0 rgba(255, 255, 255, 0.05)`) simulates light striking the top edge of a physical beveled surface.
3. **Engraved Inset Wells**: Sunken areas for telemetry graphs and code blocks use multi-stop inset shadows (`inset 0 1px 3px 0 rgba(0,0,0,0.6)`).
4. **Performance by Design**: Solid neumorphism renders with minimal GPU compositing overhead. In dense node graphs with 500+ elements, it maintains a steady 60 FPS where glassmorphism drops frames.

## Solid Neumorphism vs Prohibited Glassmorphism

| Characteristic | NXTQR Solid Neumorphism | Generic Glassmorphism |
| :--- | :--- | :--- |
| **Surface Opacity** | 100% Solid (`#0A0A0A`, `#141414`) | 40-70% Translucent (`bg-white/10`) |
| **Backdrop Filter** | None (`backdrop-blur-none`) | Heavy (`backdrop-blur-md` / `blur-xl`) |
| **GPU Rasterization** | Instant, zero frame hitching | Severe GPU spikes during canvas pan/zoom |
| **Contrast Reliability**| Constant, WCAG AAA compliant | Unpredictable over varying backgrounds |
| **Design Character** | High-precision engineering tool | Decorative consumer AI dashboard trope |

## CSS & Token Specification

```css
/* Tactile Raised Level 1 */
.nxtqr-raised {
  background-color: #0A0A0A;
  border: 1px solid #262626;
  box-shadow: 
    0 1px 2px 0 rgba(0, 0, 0, 0.5),
    inset 0 1px 0 0 rgba(255, 255, 255, 0.03);
}

/* Tactile Engraved Level 3 */
.nxtqr-inset {
  background-color: #1A1A1A;
  border: 1px solid #262626;
  box-shadow: 
    inset 0 1px 3px 0 rgba(0, 0, 0, 0.6),
    inset 0 0 1px 0 rgba(0, 0, 0, 0.4);
}
```
