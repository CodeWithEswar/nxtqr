Badges communicate discrete status, counts, versions, and security clearance levels.

## Overview

Per NXTQR engineering standards, **badges must never be used for purely decorative branding**. Every badge must convey actionable telemetry: execution status (`SUCCESS`, `FAILED`), package versions (`v1.4.2`), or membership roles (`OWNER`, `MEMBER`).

## Usage

```tsx
import { Badge } from "@nxtqr/ui";

export function WorkerStatusBadge({ isOnline }: { isOnline: boolean }) {
  return (
    <Badge variant={isOnline ? "success" : "destructive"}>
      {isOnline ? "OPERATIONAL" : "DISCONNECTED"}
    </Badge>
  );
}
```
