Motion in NXTQR communicates state transitions and spatial continuity with mechanical precision. Transitions avoid bouncy or cartoonish physics; instead, they employ **controlled deceleration curves** that resolve quickly to keep developer interactions snappy.

## Timing Scale & Duration Tokens

NXTQR defines six standardized duration tokens:

| Token Name | Duration | Milliseconds | Application |
| :--- | :--- | :--- | :--- |
| **`instant`** | `0.08s` | `80ms` | Micro-clicks, radio toggles, checkbox checkmarks |
| **`fast`** | `0.14s` | `140ms` | Hover states, button press depth, tooltip fades |
| **`normal`** | `0.20s` | `200ms` | Dropdown menus, popovers, select item highlights |
| **`smooth`** | `0.28s` | `280ms` | Modal dialogs, confirmation alerts, toast entries |
| **`panel`** | `0.34s` | `340ms` | Slide-out sheets, resizable sidebars, drawers |
| **`emphasis`** | `0.42s` | `420ms` | Major layout reflows, view mode transitions |

## Easing Curves

```css
:root {
  --ease-standard: cubic-bezier(0.2, 0.0, 0.0, 1.0);  /* Standard snappy curve */
  --ease-enter:    cubic-bezier(0.0, 0.0, 0.2, 1.0);  /* Decelerating entrance */
  --ease-exit:     cubic-bezier(0.4, 0.0, 1.0, 1.0);  /* Accelerating exit */
  --ease-linear:   linear;                            /* Spinners & progress */
}
```

## Motion for React Implementation

NXTQR visualizers use Motion for React (`framer-motion`) with pre-configured variants:

```tsx
import { motion } from "framer-motion";
import { motionDuration, motionEasing } from "@nxtqr/design-system";

export const modalVariants = {
  hidden: { opacity: 0, scale: 0.96, y: 8 },
  visible: {
    opacity: 1,
    scale: 1,
    y: 0,
    transition: {
      duration: motionDuration.smooth, // 0.28s
      ease: motionEasing.enter,        // [0, 0, 0.2, 1]
    },
  },
  exit: {
    opacity: 0,
    scale: 0.98,
    transition: {
      duration: motionDuration.fast,   // 0.14s
      ease: motionEasing.exit,         // [0.4, 0, 1, 1]
    },
  },
};
```

## Accessibility: `prefers-reduced-motion`

Per WCAG 2.1 Criterion 2.3.3, NXTQR respects user preferences for reduced motion. When enabled, all non-essential spatial movements collapse into simple instant opacity fades or zero-duration swaps:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

## Prohibited Motion Patterns

- **No Continuous Floating Blobs**: Never add animated glowing orbs or continuous floating particles behind dashboards.
- **No Bouncy Overshoot in UI Controls**: Menus, tooltips, and dialogs must not bounce past their target bounding box.
- **No Infinite Keyframe Spinners on Inactive Elements**: Keyframe loops are reserved exclusively for active background operations.
