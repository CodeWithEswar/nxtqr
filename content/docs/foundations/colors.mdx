The NXTQR color system is divided into two strict layers: **Structural Grayscale Hierarchy** and **Dynamic User Accents**.

## Grayscale Hierarchy

The dark theme baseline uses pure black (`#000000`) without any navy, slate, or AI-dashboard gradients:

| Surface Level | Hex Value | Role & Application |
| :--- | :--- | :--- |
| **Canvas / Base** | `#000000` | Full-page backdrop and infinite canvas viewport |
| **Surface** | `#0A0A0A` | Container backgrounds, cards, and sidebars |
| **Elevated Surface** | `#141414` | Dialogs, floating inspectors, dropdowns, popovers |
| **Secondary Surface** | `#1A1A1A` | Inset wells, active toolbar items, selected rows |
| **Border** | `#262626` | Structural dividers and container outlines |
| **Subtle Border** | `#1C1C1C` | Internal row separators and table grid borders |
| **Foreground** | `#FFFFFF` | Primary white text and high-contrast symbols |
| **Muted Text** | `#A3A3A3` | Secondary descriptions, captions, and metrics |
| **Disabled Text** | `#737373` | Inactive controls and unselected tabs |

```css
:root {
  --background: #000000;
  --foreground: #ffffff;
  --surface: #0a0a0a;
  --elevated-surface: #141414;
  --secondary-surface: #1a1a1a;
  --border: #262626;
  --subtle-border: #1c1c1c;
  --muted-foreground: #a3a3a3;
  --disabled-foreground: #737373;
}
```

## Calibrated Pure Accent Presets

Users configure their personal studio environment from calibrated pure saturated presets satisfying WCAG 2.1 AA/AAA:

| Preset Name | Hex Value | Accessible Foreground | WCAG Ratio |
| :--- | :--- | :--- | :--- |
| **Monochrome** | `#FFFFFF` | `#000000` | 21:1 (AAA) |
| **Pure Red** | `#FF0000` | `#FFFFFF` | 4.8:1 (AA) |
| **Pure Orange** | `#FF6600` | `#000000` | 8.2:1 (AAA) |
| **Pure Yellow** | `#FFD600` | `#000000` | 14.1:1 (AAA) |
| **Pure Green** | `#00CC66` | `#000000` | 8.5:1 (AAA) |
| **Pure Blue** | `#0066FF` | `#FFFFFF` | 4.6:1 (AA) |
| **Pure Violet** | `#8000FF` | `#FFFFFF` | 6.2:1 (AAA) |
| **Pure Pink** | `#FF0099` | `#FFFFFF` | 4.7:1 (AA) |

## Semantic Status Tokens

Status colors are strictly functional and independent from the user's selected accent:

| Status          | Value     | Purpose                                                |
| :-------------- | :-------- | :----------------------------------------------------- |
| **Destructive** | `#FF0000` | Critical errors, destructive actions, failed builds    |
| **Success**     | `#00CC66` | Successful completions, verified tests, online workers |
| **Warning**     | `#FFD600` | Non-blocking warnings, degraded simulation performance |

## CSS Semantic Classes

Always reference semantic Tailwind CSS classes rather than hardcoded hex values:

- `bg-background` and `text-foreground`
- `bg-surface` and `border-border`
- `bg-accent` and `text-accent-foreground`
- `border-accent` and `ring-accent`
