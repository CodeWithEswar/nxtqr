Per NXTQR Constitution §3.4, the platform enforces a **strict border radius standard** of `rounded-md` (`0.375rem / 6px`) across all rectangular components. Arbitrary corner rounding reduces architectural discipline and visual coherence in technical tooling.

## The Primary Architectural Rule

Every rectangular surface—including **Buttons**, **Inputs**, **Cards**, **Dialogs**, **Sheets**, **Popovers**, **Tabs**, **Toolbars**, and **Canvas Nodes**—must strictly use `rounded-md`:

```tsx
// Mandatory standard for all rectangular controls
<button className="rounded-md border border-border bg-surface px-4 py-2">
  Engineering Button
</button>
```

### Prohibited Classes

The following Tailwind border radius utilities are strictly prohibited on rectangular UI elements:
- `rounded-none` (except for full-bleed viewport canvas or segmented group interiors)
- `rounded-sm` (2px - too sharp for modern sub-pixel anti-aliasing)
- `rounded-lg` (8px - excessive rounding softens engineering aesthetic)
- `rounded-xl` / `rounded-2xl` (12px / 16px - consumer mobile app aesthetic, prohibited)
- `rounded-full` on rectangular buttons (pill buttons are forbidden)

## Permitted Circular Exceptions

Circular geometry (`rounded-full`) is permitted **only** on intrinsically circular elements:

1. **User Avatars**: Circular profile pictures (`rounded-full h-8 w-8`).
2. **Radio Button Indicators**: Circular selection dots.
3. **Loading Spinners**: Circular SVG spinners (`rounded-full animate-spin`).
4. **Status Dot Badges**: 6px status pips indicating operational telemetry.

## Concentric Nested Radius Math

When nesting containers (such as an inner code block inside an elevated card), maintaining optical coherence requires adjusting the inner radius according to the formula:

`R_inner = Math.max(0, R_outer - Padding)`

Where `R_outer` is the outer corner radius (6px) and `Padding` is the interior inset:
- If outer radius is **6px** and padding is **4px**, inner radius should be **2px** (`rounded-xs`).
- If outer radius is **6px** and padding is **8px**, inner radius should be **0px** (sharp square).

Failing to deduct padding creates optical "corner clashing" where nested curves appear pinched or distorted.
