# NXTQR — Product Overview

## Mission

NXTQR is an interactive visual engineering studio designed for engineers, architects, and technical learners. It combines visual graph canvas editing, discrete event simulation, and code execution tracing across multiple computer science and system architecture domains.

## Planned Visualizer Modules

1. **System Design Visualizer** (First planned feature in Phase 02)
2. **RAG Pipeline Visualizer**
3. **AI Agent Workflow Visualizer**
4. **Database & SQL Visualizer**
5. **Data Structures & Algorithms Visualizer**
6. **Computer Networking Visualizer**
7. **Cloud Infrastructure Visualizer**
8. **CI/CD Pipeline Visualizer**
9. **Operating Systems Visualizer**

## Foundational Principle

**One platform, multiple visualizers, shared engineering infrastructure.**
All visualizers share the same UI primitives, theme system, canvas coordinate engines, schema migration pipelines, database tables, and Cloudflare compute boundaries.
